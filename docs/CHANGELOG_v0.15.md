# Waypoint: Cube Odyssey v0.15 — Marketplace

## Cosmetics Marketplace
- Added a permanent coin-funded Marketplace / Wardrobe at safe waypoints.
- Added cosmetic slots: Skin, Head, Back, and Face.
- Added 13 launch cosmetics with multiple price tiers.
- Purchased cosmetics are owned permanently and can be re-equipped without cost.
- Cosmetics are visual only and do not change combat stats.

## Character customization
- Marketplace body skins override the base cube tint.
- Added procedural voxel Trail Cap, Moon Hood, Waypoint Crown, Traveler Pack, Lantern Pack, Road Cape, Wanderer Scarf, Scout Goggles, and Star Mark.
- Character visuals refresh immediately after buying/equipping/clearing a cosmetic.

## Save compatibility
- Save schema upgraded to version 9 with migration from versions 1–8.
- Existing saves receive empty cosmetic ownership/equipment fields automatically.
