# Waypoint: Cube Odyssey v0.9

## UI
- Gameplay popups are smaller and anchored at bottom center.
- Combat card is reduced in size to keep the center road visible.
- Fishing uses a compact bottom-center timing card.

## Audio
- Expanded original procedural bard-style music from 3 to 5 variants per context.
- Added camp, road, fishing, campfire, and boss music moods.
- Added procedural fishing splash/catch sounds.
- Added looping roadside campfire ambience with synthesized cricket calls and fire crackle.

## Roadside encounters
- Added optional roadside campfires for a quiet ambient pause.
- Added fishing pools with an expanding/contracting ripple timing mechanic.
- Added permanent gems, visible gem pickups, and fishing gem rewards.
- Added random roadside gear caches.
- Added a Gem Forge: spend 6 gems at a safe waypoint for an immediate Rare+ gear roll.

## Routes and difficulty
- Added Frostfang Pass: hard route with more elites, winter pressure, and stronger gem rewards.
- Added Whispering Fen: hard route with more fishing, caches, and relic progression.
- Threat scale expanded to 5 levels.

## Environment
- Rebalanced all environment palettes toward softer, lower-contrast colors.
- Winter lighting and snow were significantly darkened to reduce overexposure.
- Maximum brightness preset was lowered slightly for more comfortable viewing.

## Save compatibility
- Save schema upgraded to version 8 with migration from versions 1–7.
