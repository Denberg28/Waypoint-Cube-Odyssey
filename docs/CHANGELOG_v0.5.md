# Waypoint: Cube Odyssey v0.5

## Gameplay & pacing
- Kept the focused short-stage structure for each trail.
- Added random trail environments: Sunny, Cloudy, Raining, Sand, and Winter.
- Added harder suspense encounters that can appear as the run progresses: Bramble Fang, Storm Wisp, and Dune Golem.
- Rebalanced enemy rewards and damage for better risk/reward pacing.

## Presentation
- Reduced environment overexposure by lowering lighting intensity and darkening road/terrain materials.
- Added stronger environmental identity per trail with different sky, ground, and scenery palettes.
- Added fight pop-up text states: FIGHT, WIN, and LOSS.
- Added special pop-ups for Legendary and Unique item discoveries.

## Gear & rewards
- Added new Legendary and Unique permanent gear entries.
- Improved duplicate reward values for higher-rarity gear.
- Updated camp collection display to track the current total gear pool.

## Save compatibility
- Save data migrates to version 5 and preserves older runs.
