# Codex engineering handoff

This directory is the repository-side bridge between the automated Gemini analysis pipeline and **Codex used through the ChatGPT product**.

It intentionally does **not** contain an OpenAI API integration. That keeps Codex work in the user's ChatGPT/Codex workflow instead of introducing separately billed OpenAI API calls from GitHub Actions.

## Flow

1. Hourly Gemini beta testers generate bounded synthetic playtest evidence.
2. The World Architect resolves spatial-development implications.
3. `python -m ai_lab.codex_backlog` converts code-relevant evidence into focused Markdown tasks under `codex_backlog/queue/`.
4. Open one queue task in Codex, working from `ai-development`.
5. Codex reads `/AGENTS.md`, implements one task, runs validation, and prepares a reviewable change/PR.
6. Source changes remain human-reviewed; the repository never auto-merges them.

## Efficiency rules

- One Codex task at a time.
- Prefer P1 reproducible bugs before P2/P3 feature work.
- Do not ask Codex to rediscover the entire roadmap; Gemini already performs the high-frequency discovery pass.
- Keep tasks bounded enough to review in one PR.
- Do not add an `OPENAI_API_KEY` GitHub secret for this workflow.

`LATEST.md` and `manifest.json` are generated by the automation when actionable source-code work is available.
