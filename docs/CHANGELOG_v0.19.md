# Waypoint: Cube Odyssey v0.19

- JUMP can now vault over a thorn/spike tile and land two rows ahead.
- Normal walking still advances one row.
- If no jumpable obstacle is directly ahead, JUMP keeps its normal one-row behavior.
- Thorn tiles now display a small JUMP telegraph.
- Long obstacle jumps use a higher, slightly longer animation arc.
- Enemies and interactive encounter tiles are not bypassed as obstacles.
