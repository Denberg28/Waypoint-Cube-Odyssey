# Waypoint: Cube Odyssey v0.13

- Character selector and normal popup cards no longer use internal ScrollContainers.
- Standardized popup typography: caption, body, button, heading, and title sizes.
- Enlarged normal popup card height enough to show complete simple dialogs without scrolling.
- Simplified character selection and inventory/color controls to reduce visual crowding.
- Help and Settings copy shortened for quick scanning.
- Collection window now auto-equips and shows only the active best-in-slot summary; no gear browsing list remains.
