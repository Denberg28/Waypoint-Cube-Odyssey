# Waypoint: Cube Odyssey v0.18

- Added walk/run-style movement between normal road tiles.
- Added alternating voxel foot and arm swing plus subtle body bob while walking.
- Preserved jump as a separate forward movement action.
- Keyboard: A/Left = walk left, W/Up = walk forward, D/Right = walk right, Space = jump forward.
- Added a dedicated JUMP button to the lower-left movement dock.
- Kept legacy `do_hop()` / `hop_to()` aliases for test and save-era compatibility.
