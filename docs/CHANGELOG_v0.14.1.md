# Waypoint: Cube Odyssey v0.14.1 — Window Safety Pass

- Standardized all transient UI cards around one bottom-safe sizing system.
- Normal popups now calculate height from their content and the current viewport instead of a hard 320 px cap.
- Equipment, character select, route select, fight, and fishing cards share consistent widths/margins.
- Collection copy was shortened to reduce vertical pressure while preserving Gem Forge, potions, loadout, and color controls.
- Bottom controls are kept above a shared safe margin at 1280×800 and other viewport heights.
